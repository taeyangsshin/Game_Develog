## 기록 방법

README에는 프로젝트 소개·현재 상태·문서 링크를 유지합니다. 상세 설계는 별도 문서에, 작업 기록은 게임별 devlogs 폴더에 날짜별로 추가합니다.
과거 일지의 당시 판단은 보존하고, 변경된 결정은 추가 기록과 최신 설계에 반영합니다.
제안·확정된 방향·실제 구현 완료를 구분하며, 구현 완료에는 결과물과 테스트 근거를 남깁니다.
문서를 추가하거나 이동하면 해당 프로젝트와 저장소 메인 목차도 함께 갱신합니다.
대화에서 결론·결정·방향 변경이 생기면 별도 요청 없이 관련 설계와 날짜별 일지에 기록합니다. 검토 아이디어와 합의한 방향은 구분합니다.
