# 펫 미용 게임

## 현재 상태
초기 기획 단계입니다. 펫 미용 게임부터 개발하기로 했으며, 아래 플레이 흐름과 범위는 첫 구현을 위한 제안입니다.
개발 엔진, 2D/3D 여부, 목표 플랫폼, 개발 인원과 일정은 아직 정하지 않았습니다.

## 기본 아이디어
손님의 요청을 확인하고 펫을 씻기고 손질한 뒤 결과를 평가받는 게임입니다.

## 플레이 흐름
손님 접수 → 요청 확인 → 목욕 → 말리기 → 빗질·털 손질 → 평가·보상 → 다음 손님

## 첫 버전의 목표
- 펫 1종
- 주문 1개
- 미용 공간 1곳
- 목욕, 말리기, 빗질과 간단한 부위별 손질
- 결과 화면과 다시 시작
- 손님 한 명을 처음부터 끝까지 완료할 수 있는 실행 버전
