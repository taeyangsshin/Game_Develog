# 반려동물 미용 게임

## 현재 방향

PC에서 짧은 에피소드로 플레이하고, 전체 이야기에는 엔딩이 있는 미용 게임을 만든다.
대기 화면은 2D, 미용할 때는 간단한 3D를 사용한다.
현재는 기획과 개발 준비 단계이며 실행 게임은 아직 없다.

## 핵심 경험

- 털의 질감과 도구를 움직인 경로에 따른 변화로 직접 미용하는 느낌을 준다.
- 강아지와 고양이를 모두 고려한다. 강아지 / 고양이 / 혼합의 방문 구성을 검토한다.
- 개별 동물의 친밀도와 미용·방문 기록이 다음 플레이로 이어진다.
- 짧은 손질과 대화를 반복하며 단골과 가까워지고 엔딩에 도달한다.

## 기본 흐름

타이틀 → 방문 구성 → 2D 대기실 → 대화·요청 → 3D 미용 → 결과·기록 저장 → 다음 에피소드 → 엔딩

## 첫 개발 목표

**동물 한 마리를 2D 대기실에서 선택해 임시 3D 미용 공간으로 들어갔다 돌아오는 M0**부터 만든다.
이후 M1 털 손질 체험 → M2 친밀도·저장 → M3 에피소드 하나 → M4 고양이와 방문 구성 → M5 엔딩 순서로 확장한다.

## 제안과 미정 사항

- 엔진은 미정. Unity는 추천 후보.
- '가게를 맡는 일주일과 마지막 기념사진'은 후보 시나리오.
- 게임 이름, 등장 동물, 에피소드 수와 플레이 시간은 미정.
- 세 방문 구성을 처음부터 열지 또는 자유 미용에 둘지 미정.
- 염색·액세서리 판매는 검토 아이디어. PC 완결형 구조에 맞춰 추후 재검토한다.
- 고양이 미용 작업과 품종 특성은 별도 조사 후 반영한다.
