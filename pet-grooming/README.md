# 펫 미용 게임

## 현재 상태
초기 기획 단계. 아래는 2026-10-26 대화에서 정한 최신 방향이며 게임 구현 완료를 뜻하지 않습니다.

## 핵심 경험
내 손으로 털을 다듬어 실제로 미용하는 듯한 감각을 느끼고, 짧은 플레이를 반복하며 강아지별 관계와 기록을 쌓는 게임입니다.

## 정한 방향
- 대기 화면은 2D로 표현하고, 미용할 때만 간단한 3D를 사용합니다.
- 털의 질감과 도구 사용에 따른 변화가 핵심입니다.
- 정해진 부위를 클릭해 완료하는 방식보다 도구를 움직인 경로·방향·범위가 결과에 남는 경험을 지향합니다.
- 짧게 플레이해도 기록이 저장되고 다음 접속에서 이어집니다.
- 강아지별 애정도·친밀도를 두고, 반복해서 만나면 관계가 가까워집니다.

## 플레이 흐름 초안
2D 대기실 → 강아지 선택 → 오늘 할 손질 확인 → 3D 미용 → 결과·관계 변화 저장 → 2D 대기실

## 화면 구성
- **2D 대기실:** 강아지 선택, 이름·기분·친밀도 확인.
- **3D 미용:** 강아지와 미용대에 집중해 털과 도구 조작을 보여줍니다.
- **결과·기록:** 미용 전후 모습, 방문 기록과 친밀도 변화를 확인합니다.

## 첫 버전 제안
강아지 한 마리를 2D 대기실에서 선택하고 3D에서 짧게 손질합니다. 결과와 친밀도를 저장한 뒤 재실행해 같은 강아지를 다시 만납니다.
처음부터 목욕·건조·빗질·커트를 전부 완성하기보다 손질 도구 하나의 감각과 저장까지 검증합니다.

## 확정 전 제안
- Unity를 우선 후보로 검토하되 개발 엔진은 아직 확정하지 않았습니다.
- 고정 카메라에 확대·강아지 회전을 제공하는 방식을 검토합니다.
- 1회 3~5분은 테스트할 목표치이며 확정 시간이 아닙니다.
- 첫 도구 후보는 클리퍼입니다. 털을 작은 영역에서 직접 다듬는 실험 후 결정합니다.
- 친밀도는 표정·접근·편안함 등 행동으로 보여주는 방식을 검토합니다.
