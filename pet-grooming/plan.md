# 펫 미용 게임 개발 단계

문서 작성일: 2026-10-26
상태: 구현 전 개발 계획
기본 가정: 마우스로 도구를 선택하고 펫에게 사용하는 방식. 화면 방식과 엔진은 미정입니다.
완료 기준을 충족한 뒤 다음 단계로 넘어가며, 실제 일정은 팀 규모와 제출 기한 확인 후 정합니다.

## 1단계 — 기본 규칙과 범위 결정
### 할 일
- 플레이어가 직원인지 가게 주인인지 정한다.
- 첫 펫 한 종류와 첫 주문 한 개를 정한다.
- 2D/3D, 엔진, 플랫폼, 조작 방식을 정한다.
- 접수부터 평가까지 화면을 종이에 그린다.
- 실제 미용 절차를 참고할 자료를 찾고 게임용 단순화와 구분한다.

### 완료 기준
손님 한 명의 시작·플레이·결과를 설명할 수 있고 첫 버전의 기능 목록이 정해져 있다.

## 2단계 — 테스트 공간과 기본 조작
### 할 일
- 임시 도형으로 미용대, 펫, 도구 버튼을 배치한다.
- 도구 선택과 선택 상태 표시를 만든다.
- 클릭·드래그로 펫의 대상 부위를 판별한다.
- 도구 사용 시 색 변화나 효과로 반응을 표시한다.
- 접수, 미용, 결과 화면으로 이동할 수 있게 한다.

### 완료 기준
도구를 선택해 펫에게 사용하면 반응이 나타난다. 잘못된 부위를 눌러도 진행이 깨지지 않는다.

## 3단계 — 목욕 기능 하나 완성
### 할 일
- 씻어야 하는 얼룩을 배치한다.
- 스펀지로 문지르면 거품이 생기게 한다.
- 물로 헹구면 얼룩과 거품이 사라지게 한다.
- 깨끗해진 정도와 완료 상태를 표시한다.
- 완료했을 때만 다음 단계로 이동하게 한다.

### 구현 범위
초기에는 영역별 색 또는 텍스처 변경으로 구현해도 된다. 실제 물리 기반 물·거품 시뮬레이션은 필수가 아니다.

### 완료 기준
시작부터 목욕 완료까지 조작할 수 있다. 반복해서 문질러도 진행 수치가 최대치를 넘어가지 않으며 재시작 시 초기화된다.

## 4단계 — 말리기와 빗질
### 할 일
- 드라이어를 사용하면 영역별 젖은 표시가 사라지게 한다.
- 빗질하면 엉킨 털 표시가 정돈되게 한다.
- 필요한 행동을 알려주는 짧은 안내를 넣는다.
- 목욕·건조·빗질의 상태를 이어서 관리한다.

### 완료 기준
목욕 → 말리기 → 빗질이 순서대로 이어지고, 완료 표시와 펫의 외형 상태가 일치한다.

## 5단계 — 털 손질과 주문 판정
### 할 일
- 주문 내용을 작업 중에도 확인할 수 있게 한다.
- 손질 가능한 부위를 정한다.
- 도구를 사용하면 부위별 손질 전·후 외형이 바뀌게 한다.
- 완료한 부위와 손님의 요청을 비교해 주문 달성도를 계산한다.

### 구현 범위
초기에는 부위별 모델·이미지·상태를 전환한다. 털 한 올씩 자르는 기능과 복잡한 털 시뮬레이션은 이후 검토한다.

### 완료 기준
요청한 부위를 손질했을 때와 빠뜨렸을 때의 평가가 다르고, 결과의 이유를 확인할 수 있다.

## 6단계 — 손님 한 명의 전체 플레이 완성
### 할 일
- 접수 → 요청 → 목욕 → 말리기 → 빗질·손질 → 결과 → 다음 손님을 연결한다.
- 깨끗함, 정돈 상태, 주문 달성도를 결과에 표시한다.
- 보상 지급과 새 주문 시작을 연결한다.
- 같은 주문에서 보상이 중복 지급되지 않게 한다.
- 처음부터 다시 시작하는 기능을 만든다.

### 완료 기준
실행 후 손님 한 명을 끝까지 마치고, 모든 상태가 초기화된 새 주문을 시작할 수 있다.

## 7단계 — 표현과 안정성 개선
### 할 일
- 펫의 표정과 반응 애니메이션을 넣는다.
- 거품·물·털 효과와 도구 소리를 추가한다.
- 도구 버튼, 진행 표시, 손질 전후 비교 화면을 다듬는다.
- 저장·불러오기 범위를 정하고 구현한다.
- 다른 사람에게 플레이를 맡겨 조작 실수와 막히는 지점을 기록한다.
- 수정 후 다시 확인하고 실행 파일을 만든다.

### 완료 기준
처음 보는 사람도 기본 안내만으로 한 주문을 완료한다. 재시작과 저장·불러오기 후 상태가 올바르며 목표 기기에서 실행된다.

## 첫 버전 이후 확장 후보
- 펫 종류와 손님 주문 추가
- 도구 구매와 가게 꾸미기
- 시간 제한 또는 펫 기분 관리
- 더 다양한 미용 스타일

## 가장 먼저 구현할 것
테스트 공간 → 도구 선택 → 대상 부위 클릭·드래그 반응 → 목욕 완료 판정 순서로 진행한다.
캐릭터와 배경은 임시 리소스로 시작하고 한 주문이 끝까지 작동한 뒤 미술을 교체한다.
