# 개발 계획 — 단계별 진행

수정일: 2026-10-26
현재 목표: PC에서 짧은 에피소드로 플레이하고 엔딩에 도달하는 반려동물 미용 게임.
화면: 2D 대기실 + 3D 미용.
강아지·고양이·혼합 방문 구성을 검토한다.
엔진은 아직 미정이며 Unity는 후보이다.

전체 설계와 완료 기준은 [프레임워크 v0.1](framework.md)을 따른다.
이전의 모바일 우선 제안보다 최신 PC 우선 방향을 따른다.
'일주일과 기념사진' 이야기는 후보 시나리오이며 최종 채택은 아직 결정하지 않았다.

## 개발 순서
1. **M0 화면 뼈대:** 타이틀 → 2D 대기실 → 임시 3D 미용 공간 → 복귀.
2. **M1 손맛 검증:** 작은 털 영역과 도구 하나로 경로에 따라 손질.
3. **M2 관계·저장:** 동물별 친밀도·방문 결과 저장과 재실행 복원.
4. **M3 에피소드 하나:** 대화·요청 → 손질 → 결과·다음 방문.
5. **M4 고양이·방문 구성:** 고양이 작업 조사와 강아지·고양이·혼합 선택.
6. **M5 완결:** 반복 방문·관계 변화·앨범과 엔딩.
