# 펫 미용 게임 개발 단계

작성·수정일: 2026-10-26
상태: 기획 / 구현 전
화면 방향: 2D 대기실 + 간단한 3D 미용
엔진: 미정. Unity는 추천 후보.
이 문서는 초기의 '목욕부터 전체 미용 절차 구현' 계획을 최신 핵심 경험에 맞춰 조정한 계획입니다.

## 1. 화면과 첫 체험 범위 고정
- 첫 강아지와 도구 한 개, 손질할 몸통 영역을 정합니다.
- 엔진·플랫폼·팀 규모·기한을 정합니다.
- 2D 대기실 → 3D 손질 → 결과 → 대기실의 화면 스케치를 만듭니다.
- 2D 그림과 3D 모델에서 같은 강아지로 보이도록 색·무늬·특징을 맞춥니다.

**완료 기준:** 한 번의 짧은 플레이와 다음 접속에서 이어질 요소가 설명됩니다.

## 2. 털의 질감과 도구 반응 실험 — 가장 먼저 구현
- 전체 강아지 대신 작은 곡면이나 몸통 일부에서 시작합니다.
- 털의 복슬한 윤곽과 결이 보이는 표현을 비교합니다.
- 도구가 닿은 영역과 지나간 경로·방향이 결과에 반영되게 합니다.
- 클리퍼를 첫 도구로 선택한다면 지나간 부분만 짧아지고 이미 자른 상태가 유지되게 합니다.
- 도구가 떨어진 곳에는 변화가 생기지 않게 합니다.
- 도구 소리, 떨어지는 털과 짧은 움직임을 맞춰 감각을 확인합니다.

**완료 기준:** 정해진 완료 버튼에 의존하지 않고 손질 결과의 차이를 볼 수 있습니다. 플레이어가 스스로 '조금 더 다듬을 곳'을 발견하는지 확인합니다.

**미정:** 털 렌더링·모델·변형 방식은 기술 실험 후 선택합니다. 실제 털 한 올 전체의 물리 시뮬레이션을 필수로 가정하지 않습니다.

## 3. 강아지 한 마리에 손질 적용
- 실험한 표현을 강아지 모델에 적용합니다.
- 강아지의 확대와 회전, 손질할 부분 선택을 검토합니다.
- 도구 접촉·손질 상태·완료 처리를 연결합니다.
- 미용 전후 모습의 차이가 보이도록 결과를 만듭니다.

**완료 기준:** 도구 하나로 짧은 손질을 끝낼 수 있고, 반복 조작해도 상태가 깨지지 않습니다.

## 4. 2D 대기실과 3D 미용 연결
- 2D 대기실에서 강아지를 선택합니다.
- 동일한 고유 ID로 연결된 강아지를 3D 미용 화면에 불러옵니다.
- 미용 결과를 반영하고 2D 대기실로 돌아옵니다.
- 화면 전환 중 입력이 중복되거나 다른 강아지의 데이터가 섞이지 않게 합니다.

**완료 기준:** 대기실 → 미용 → 결과 → 대기실을 한 번에 끝낼 수 있습니다.

## 5. 개별 친밀도와 기록 저장 — 첫 버전의 필수 기능
- 강아지 ID, 이름, 외형 정보, 친밀도, 방문 횟수와 마지막 손질 기록을 저장합니다.
- 친밀도가 오르는 행동과 증가량은 별도로 정하고 행동 반응에 연결합니다.
- 미용 전후 사진 기록과 진행 중 작업의 복구 범위를 결정합니다.
- 저장·불러오기를 구현합니다. 손질 중 종료까지 지원한다면 털 변화 데이터도 저장합니다.
- 모델을 새로 불러와도 이름·외형·관계가 같은 강아지로 이어지게 합니다.

**완료 기준:** 종료 후 재실행해 같은 강아지의 친밀도와 기록이 복구됩니다. 두 강아지로 검사할 때 서로의 정보가 섞이지 않습니다.

**중요:** 결과 사진만 저장하는 것과 실제 손질 상태를 복구하는 것은 다르므로 구분해서 검증합니다.

## 6. 짧게 플레이하고 다시 만나고 싶은 흐름 검증
- 매번 전체 미용을 강제할지, 짧은 요청 하나를 제시할지 테스트합니다.
- 3~5분은 초기 제안치로 두고 실제 플레이 시간을 측정해 조정합니다.
- 친밀도에 따른 인사·표정·몸을 맡기는 반응을 작은 범위에서 구현합니다.
- 다른 사람이 손질 감각과 재방문 동기를 느끼는지 확인합니다.

**완료 기준:** 짧게 한 번 끝낼 수 있고 다시 접속할 때 지난 관계와 작업 결과를 알아볼 수 있습니다.

## 7. 추가 도구·미술·안정성 확장
- 핵심 체험 검증 후 빗질·젖음·건조·가위 같은 도구와 변화를 추가합니다.
- 펫 종류, 방문 요청, 결과 화면과 소리를 확장합니다.
- 목표 기기에서 털 표현 성능을 확인합니다.
- 저장 실패·재시작·화면 전환·중복 보상 등의 문제를 확인합니다.

**완료 기준:** 선택한 기기에서 짧은 플레이와 다음 접속이 안정적으로 이어집니다.
