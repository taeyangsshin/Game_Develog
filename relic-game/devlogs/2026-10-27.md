# 2026-10-27 — 유물 게임 상세 기획

## 작업 기록

오늘은 유물 게임의 스토리 상세 기획으로 작업 주제를 전환했다. 다섯 대상을 선정한 초안과 주인공 동기, 진입 규칙, 챕터별 사연·한·퍼즐·해소 장면, 최종 갈등과 엔딩을 작성했다. 실제 유물·설화·건축유산을 구분하고 조사 출처 및 추가 확인 항목을 기록했다.

다음 작업은 1장 장면별 대사와 퍼즐 배치도를 구체화하는 것이다. 현재는 문서 기획 단계이며 게임 코드·모델·음악·컷씬을 구현한 상태가 아니다.

## 문서 점검과 정리

- 전체 스토리와 퍼즐 설계를 [상세 기획](../story-design.md)으로 분리했다.
- [프로젝트 README](../README.md)는 소개·현재 상태·목차로 정리했다.
- 실물 유물·건축유산·설화 속 물건의 회복 규칙을 구분했다.
- 활 챕터에서 과거를 바꾸는 것처럼 읽히던 부분을 기존 도착 기록을 발견하는 흐름으로 명확히 했다.
- 메인 목차, 이전 플랫폼 제안, 미용 게임 단계 순서, 오래된 ZIP 안내를 함께 점검했다.

## 검증 범위

문서의 내부 링크·기획 일관성·평가 계산을 확인한다. 게임 실행 테스트와 역사 고증 최종 검토는 아직 수행하지 않았다.
